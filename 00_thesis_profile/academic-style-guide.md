## Defaults (APA 7th, English)
- **Citations:** APA 7th edition author–date in text, e.g., (Vial, 2019) or Vial (2019). Use "et al." for three or more authors from the first citation.
- **Reference list:** APA 7th, alphabetical, with a hanging indent. Include the DOI as https://doi.org/... whenever one exists.
- **Spelling:** [TO CONFIRM: British or American]
- **Person and voice:** third person preferred. Use the active voice where it reads clearly.
- **Tense:** past tense for methods and results, present tense for established knowledge and implications.
- **Hedging:** match how certain the claim is to the evidence. NEVER use causal language ("causes", "leads to") for cross-sectional correlational data.
- **Statistics:** APA 7 format. Italicize statistical symbols (*p*, *β*, *t*, *R*²). Report exact *p* values to 2–3 decimals (*p* < .001 when smaller). Put no leading zero before values that can't exceed 1.
- **Headings:** APA 7 levels 1–5.
- **Tables and figures:** numbered, with titles in italic title case and notes below.
- **Terminology:** define every acronym at first use and use each term consistently (e.g., don't switch between "digital transformation" and "digitalization" unless you define the difference).
- **Paragraphs:** a topic sentence, then evidence, then analysis, then a link back to the argument. No single-sentence paragraphs.
